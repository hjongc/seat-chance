# 제품 원칙

앉을각은 “지금 이 구간에서 어느 칸·문 근처에 서야 더 나은가”에 답하는 서비스입니다.

## 핵심 가치

- 빠르게 결정할 수 있어야 합니다.
- 결과는 확률이 아니라 상대 점수로 표현합니다.
- 추천 근거는 사용자가 납득할 수 있는 교통 데이터 기반이어야 합니다.
- 실시간 빈 좌석, 개별 승객 이동, CCTV 분석 같은 문제는 다루지 않습니다.

## 추천이 보는 요소

앉을각은 중간역에서 좌석이 비거나 이동이 생길 가능성을 추정합니다.

- 중간역 하차 수요가 많은가
- 환승역과 환승 동선이 가까운가
- 같은 역에서 새로 타는 사람이 너무 많지는 않은가
- 전체 또는 역별 혼잡도가 너무 높지는 않은가
- 좌석 기회가 목적지보다 충분히 앞선 구간에서 생기는가

## 하지 않는 것

- 실시간 좌석 수 예측
- 개별 승객 목적지 예측
- 위치 추적
- CCTV, Bluetooth, Wi-Fi 기반 혼잡 분석
- 착석 확률 퍼센트 표시

## 표현 원칙

금지:

```text
3-2 문에 서면 앉을 확률 82%
```

권장:

```text
3-2 문 앉을각 점수 82점
이 구간 내 다른 문 대비 좌석 회전 조건이 좋습니다.
```

## 현재 제품 범위

- 모바일 우선 웹 서비스
- 호선, 승차역, 하차역, 요일 유형, 출발 시간 기반 추천
- 칸·문 Top 3 추천
- 열차 레이아웃 표시
- 평일과 주말·공휴일 구분

## 확장 후보

- 사용자 피드백 수집
- PWA 설치 경험 개선
- 더 정교한 환승·출구 동선 가중치
- 노선별 레이아웃 신뢰도 표시 개선
